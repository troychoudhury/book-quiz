# Goal

A web application that allows visitors to search for a book by name or ISBN and
take a quiz. This is geared towards individual readers and not schools or home
schoolers or parents. Encourge parents to create separate accounts for each of
their children.

# Features

1. Data hydration: Create background tool that can be run to get a list of top 100 books per age starting age 6 until age
   18 from the internet. For each book use AI to generate questions for each
   chapter of the book. The questions should focus on the main theme of the
   chapter, focus on both facts and events, as well as characters and emotions, and morals, outcomes, and interpretations. The goal is to test a readers memory, comprehension, as well as language skills. The questions should be accompanied by AI generated multi-choice answers with one correct answer and other incorrect answers. In case of answers that contain lists have 'none of the above', 'all of the above', or some combination of options as choices. Store all this in a database for retrieval by web application.
1. Landing page: Show a search bar to search for books using names and ISBN.
   The search is powered by the data hydrated. Once a book is selected take to
   the quiz page. The page should not require login. But it should show a login
   and sign up on the top right.
1. Quiz page: Randomly pick 10 questions from the books question list
   previously generated by AI. Show the questions one at a time as a quiz to the user. Show the progress to the user, how many questions are complete and total questions. Once the quiz is complete if the user is not logged in ask them their email address to send them results or ask them to login to record their test result or sign up. If the user is already logged in record the users progress against this book in their profile. If the user takes the quiz for this book again then pick a question list excluding questions they have already completed. If they have completed all questions ask them if they would like to retake the quiz. Record each retake as a separate attempt so that previous attempts are retained.
1. Profile page: Show the list of books that the user has completed and their
   progress and score.

# Existing solutions

Here are some existing applications to refer for inspiration and word choices.

- https://www.whooosreading.org/ - Targetted towards schools and teachers.
- https://bookroo.com/ - Targetted towards individual readers as well as
  schools. It is dedicated towards improving reading including book clubs. Used
  the quiz for Harry Potter and it was good.
- https://swipesmrt.com/ - AI-generated questions from a image of book page.
- https://readhatch.com/ - AI-generated book questions.
- https://readnquiz.com/ - Targetted towards schools and home schoolers. Old
  style interface.
